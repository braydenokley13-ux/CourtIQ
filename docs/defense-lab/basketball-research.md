# Basketball research and model decisions

Research checked 5 October 2026. This is the initial synthesis before changing the product architecture; implementation follows these decisions. Sources are coaching instruction, not validation of the simulator's numerical constants.

## Verified evidence

1. [Joao Costa, Defending the Pick and Roll, Coach's Clipboard](https://www.coachesclipboard.net/BasketballDefensePicknRoll.html). Retrieved the full article, including high P&R quick slip, trap, hug, show/recover, re-screen, pop, late-clock switch and big-to-big rotation examples. It explicitly distinguishes going over/under, the screen defender's response, and weakside rotation. It says to cover weakside top, elbow and box, and shows different responses on the initial screen and re-screen. **Decision:** coverage is a bundle of independently editable rules; screen response is not interchangeable with low-man policy.
2. [James Gels, Man-to-Man Defense](https://www.coachesclipboard.net/M2MDefense.html). Retrieved full article. It explicitly treats one-pass denial, gap help, star-shooter stay-home and baseline rotations as coaching choices. It describes seeing ball and player, help/recover, helping the helper, and perimeter exchanges when the on-ball defender is beaten. **Decision:** helping distance, trigger and recovery are inputs. Deny/gap/stay are preferences, not universal basketball law.
3. [James Gels, Switching Man-to-Man Defense](https://www.coachesclipboard.net/basketball-switching-defense.html). Retrieved full article. It covers equal-size switches, mismatches, switching back, screen communication, step-under/stay versus step-under/switch, and selective down-screen rules. **Decision:** distinguish coverage-triggered responsibility transfer from physical movement; a switch is not an instantaneous change in floor position. Switch-all is not a universal default.
4. [USA Basketball, Youth Basketball Guidelines](https://www.usab.com/youth/development/youth-basketball-guidelines). Page retrieved successfully. The guidance is an age-specific framework, not varsity tactical evidence. **Decision:** do not import youth restrictions as universal high-school defensive rules.
5. [Basketball Immersion, Željko Obradović Partizan Ball Screen Concepts](https://basketballimmersion.com/zeljko-obradovic-partizan-ball-screen-concepts/). Full text retrieved via its public WordPress endpoint, post 27739. It distinguishes off-action **spacing principles** from two-player **coverage solutions**. It explains a tagging defender, fill-behind spacing that separates weakside receivers, the "take two" defender, short roll, deep diagonal roll, second pass, skip, screen-angle changes and consecutive actions. **Decision:** spacing/relocation belongs to a reusable action structure; the read after the first pass continues the same basketball problem rather than loading an unrelated play. A diagonal roll can lengthen the tagger's recovery. The code uses an authored diverging ball/roll route, rather than forcing both through one floor point.
6. [Basketball Immersion, The Basketball Defensive X-Out](https://basketballimmersion.com/basketball-defensive-x-out/). Full text retrieved via post 6665. It defines the weakside exchange, "in" and "out" help roles, first-pass/second-pass responsibility, and a three-player rotation in which the beaten defender may take the second pass while the helper stays with the player stopped. It explicitly frames which shot to concede as philosophy. **Decision:** an X-out is a responsibility exchange after help; it does not universally mean the low man always runs back to the same receiver. V1's two-player backside exchange is one editable authored answer, while a third-player peel/recovery chain remains an extension.
7. [Basketball Immersion, Jim Boylen defensive-system clinic summary](https://basketballimmersion.com/how-to-build-a-defensive-system/). Full text retrieved via post 5094. It connects force direction, ball-screen treatment, gap positioning, personnel, moving on release, weakside exchange and the high defender taking the first pass from baseline help. **Decision:** split/stay rules affect preparation before a pass, but a changed target still requires acceleration and reversal. The clinic's NBA percentages and claims about championship defense are context-specific and are not simulation inputs.
8. [Alan Keane, Observations from the 2019 U18 European Basketball Championships](https://basketballimmersion.com/european-basketball-championships/). Full text retrieved via post 10411. It discusses Spain/Stack with bigs staying and guards switching; middle ball screens exposing the low tag through cross-court passing; empty-corner low tags producing a two-on-one on the opposite side; and short-roll effectiveness depending on line-of-pass and receiver awareness. **Decision:** guard/big transfers can differ in Spain. Empty-side help eligibility must derive from spacing, rather than always selecting a fixed weak corner. This is junior international evidence, closer in age but not a universal US high-school template.
9. [Basketball Immersion, Concepts and Trends in FIBA Champions League](https://basketballimmersion.com/concepts-and-trends-fiba-champions-league/). Full text retrieved via post 23274. It separates peel (beaten on-ball defender leaves ball; closest helper contains) from scram (off-ball mismatch correction, often as the ball moves away), discusses popping to punish drop, post trapping from baseline, and Spain variations. **Decision:** preserve transfer **trigger** and ownership history; the same exchange primitive needs different basketball conditions. Pop is a different screener route, not a shot-probability modifier.
10. [Basketball Immersion, The Next Ball Screen Defense Explained](https://basketballimmersion.com/next-ball-screen-defense/). Full text retrieved via post 26028. It describes chasing over to peel to the next player, a gap defender sinking to switch, a player two gaps away stunting, and a different "Hot" trap position that encourages lob passes to buy recovery time. **Decision:** a coverage cannot be reduced to screen-defender movement; coordinated gap roles and permitted launch shapes must be explicit. V1's roll reader now evaluates a pocket and an authored lob shape against current body geometry.
11. [Basketball Immersion, Mastering Peel Switching](https://basketballimmersion.com/mastering-peel-switching-in-basketball/). Full text retrieved via post 35232. It gives "beat → peel → switch" cues and notes that multiple baseline attackers can require zoning rather than one-to-one switching. **Decision:** never make a global five-player permutation optimizer the universal defensive ontology.
12. [Coach's Clipboard, 2–3 Zone Defense](https://www.coachesclipboard.net/23zonedefense.html). Full text retrieved. It details on/off or bump exchanges, skip coverage, corner traps and high-post responsibilities. **Decision:** future responsibilities must support area/threat ownership; temporary guarding and permanent assignment are different concepts.

## Authentic first problem

In a high ball screen, the on-ball defender and screen defender first handle the ball/roll pair. A weakside low defender may temporarily tag the rolling screener. That commitment reduces direct protection of the weakside corner and/or a lifting receiver. The higher weakside defender can split the two until a pass identifies the first closeout; the low defender must then recover to another receiver. A backside X-out can exchange those closeouts. A long skip, receiver lift and subsequent extra pass change the time and distance available; they are continuations of the same action.

The low man is **a situational responsibility**, usually the deepest eligible weakside help defender, not permanently player D3 in the ontology. The first slice assigns it explicitly for clarity. A tag can mean an early bump, body position, stunt or sustained roll support in different programs. The model calls its chosen behavior "tag" and exposes depth plus timing so that a word does not hide a philosophy.

The offense must inspect defense. If the tag commits, roll influence improves while the weakside pair becomes harder to cover. If it stays shallow, a roll continuation becomes more attractive. If two defenders commit to the handler, the screener can stop into a short roll and read the rotation. If the screen is switched, spacing/roll options remain but ownership and recovery differ. The first read chooses among currently feasible options using modeled geometric availability and an offensive intent. Choosing "weakside lift" sets relocation/intent, not a predetermined completed skip.

## Universal structures, aliases and choices

| Universal structure | Coach language / aliases | Variable philosophy |
|---|---|---|
| Two-player screen creates ball/roll responsibilities | P&R, ball screen; screener roll/dive | over, under, switch, show, blitz, drop depth |
| Off-ball defender temporarily influences another threat | help, tag, stunt, bump | who helps, how deep, at which trigger, protected shooter |
| Leaving one threat creates another responsibility | rotation, help the helper, X-out | first backside closeout, exchange versus stay |
| Assignment transfer and physical arrival differ | switch, exchange, scram, peel | which pair transfers, trigger, recovery point |
| Offensive relocation changes passing geometry | lift, shake, replace, drift | receiver timing and spacing |
| Ball flight consumes time | skip, kick, pocket, one more | release height, pass type and read timing |

"ICE", "down" and "blue" may refer to related side-screen directional coverages but are not guaranteed synonyms. A high middle ball screen cannot be modeled by blindly copying sideline ICE geometry. In this slice the ICE option is explicitly a force-direction rule with a stated middle-screen limitation.

## Stress-test the ontology beyond this slice

- **Spain:** screener plus back screener requires an action graph with three-player screen dependencies and transfers; a two-player coverage enum cannot own the whole situation.
- **Ghost/slip:** a screen trigger must observe proximity/contact or declared action, rather than assume every screener becomes stationary.
- **Empty-side:** low-man eligibility comes from current spacing; help cannot rely on a permanent corner role.
- **Baseline drive + drift:** help trigger is penetration depth and direction; drift modifies receiver target; transfers use the same responsibility structure as tags.
- **Middle drive + 45 cut:** the help defender's player can cut behind help. An assignment attaches to a changing threat, not a static floor point.
- **Short roll:** the receiver becomes a new decision-maker; the graph continues at catch, with inside/kick options.
- **Post double + skip:** two concurrent ball responsibilities can coexist; a permutation matching each defender to one player is insufficient.
- **Zone:** areas and threats are responsibilities. "Always exactly one matchup per defender" cannot be universal.
- **Transition:** stop-ball/protect-rim precede stable matchups; positional player number does not encode responsibility.
- **Peel/scram:** emergency transfer trigger differs from called screen switch; both preserve actual velocity/history.

These are architecture checks, not claims that V1 implements the complete situations. The single polished problem is the only executable corpus item in this build.

## Simulation decisions and honesty

Use a deterministic fixed-step physical world with actual x/z velocity, acceleration limits, finite turning, simplified body separation, and a true-height ball arc. Keep presentation avatars separate. Policy chooses motion targets; physics determines when bodies arrive. The offense reads measured defender positions at graph checkpoints. Defense reads delayed world frames and responds to observed possession and spacing; it cannot see the counter identifier or a future receiver.

The current default preparation/tag/X-out answer is one researched coaching preference: a shallow tag keeps the higher defender closer to the lift; a full commitment asks that defender to split the weakside pair. "Stay" really keeps the higher defender with the lift even while the low man tags. Low-tag intercept depth is authored, not a biomechanics estimate. The first tag commitment at 0.75 s is the default edit checkpoint; basketball options become feasible at 1.1 s and the authored handler evaluation occurs at 2.1 s. Issuing a later cue can legitimately leave insufficient reversal time to protect the lift.

A roll read previews two common launch shapes: a pocket and a lob. The lob has a fixed additional 0.2 s of flight and a higher release/catch; no unbounded search raises it until it succeeds. The preview uses current modeled body capsules, raised hands and at most 0.35 s of current-velocity extrapolation. It cannot access future defensive policy frames. Fine actual-flight analysis is separate and can disagree with the preview.

An intervention is an append-only timed rule or movement cue. The engine reruns the same world/seed and activates the cue only at its tick; earlier frames, events, velocity and launched ball endpoints remain unchanged. A later target cannot teleport a player or retarget a ball in flight.

Compute timing, window intervals, distances, clearances and responsibility transfers from frames. Label acceleration, reaction, gather/read time and influence radius as model assumptions. A reachability lower bound is not measured player ability. Frame sampling and body discs are approximations; no shooting percentage, "defense score" or certainty of possession outcome. Structural conflict requires concurrent obligations with explicit modeled deadlines; an uncovered receiver alone does not prove a coach's scheme is logically impossible.

## Existing engineering retained and corrected

SEAM III has useful fixed-step motion, velocity-preserving interventions, body envelopes, fixed launched ball flight, fine pass probes, deterministic paired assumption tests and diagnostic caveats. It also precomputes offense paths/ball events and uses a global assignment optimizer that can invent responsibility exchanges. The new Lab keeps the causal/physical principles while replacing the prescribed attack catalog with connected read decisions and explicit coach-authorized transfers. Existing scenario3d content in the repository is primarily authored playback/choice teaching; it stays separate so the new executable model does not silently claim those animations were interactive simulations.

The second user commission raises the target beyond this initial model. The implementation remains a bounded P&R policy template with authored movement goals and scheduled read checkpoints. `simulateProblem` proves that physical stepping and action/read execution can consume another formation and a baseline-drive graph; it does **not** prove that the current defensive policy is a universal basketball engine. The next architectural pass must make policies and counter continuations content, add more state-triggered transitions, and turn the bounded stress set into a basketball-valid search. Keeping this limitation explicit prevents the useful primitives from being mistaken for the destination.
